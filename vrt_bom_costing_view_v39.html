自動辨識規則

  • factory exp：Direct labor、Manufacturing overhead、月份。
  • Cost Per Min：LOH、ATT MINUTES、MIN PRODUCED、STD COST PER HOUR。
  • BOM：Items／Description／Qty／Unit Price／Cost per piece or dozen。

雲端與掛載

本機先存 IndexedDB；設定既有 GAS Web App 後，可增量上傳／下載並掛到 Sewing Prod2。

雲端設定

下載時按 ID 與更新時間合併；若雲端資料較舊或 BOM 行數較少，系統會先要求確認，不會直接少覆多。

Sewing Prod2 掛載

將本檔放到 Sewing Prod2 同一網站，再以連結或 iframe 開啟；支援 embed=1、lang=zh/en/km，並可用 postMessage 傳入款式、客戶、SMV 與雲端設定。

VRT_BOM_Costing_Cloud_v1.html?embed=1&lang=zh
{ type: 'SEWING_PROD2_COSTING_CONTEXT', styleNo, customer, productionSMV, cloudEndpoint }

若要我直接加進既有選單，需再提供 Sewing Prod2 的目前 HTML／Git 專案；本版已預留相容入口。
