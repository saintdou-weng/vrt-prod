本頁做什麼／不做什麼
讀取
ERP 匯出檔（CSV／TXT／XLSX／JSON 契約）、PROD 車縫／裁剪／QC／排產／訂單／出貨排程（IndexedDB 唯讀，不建庫、不升版）
寫入
只寫本頁自己的資料庫 VRT_ERPLink（ERP 快照行、匯入批次、欄位範本、對照鍵）與雲端工具 erplink
絕不
寫回 clothes.exe／SQL、改 PROD 任何模組資料、用 API 連得上當成資料已同步、拿示範資料充當正式資料
去重
同檔重匯／改名重匯不增量（檔案雜湊＋業務鍵＋內容雜湊）；少量檔不抹掉完整資料；更正保留舊版本
雲端
沿用 Smart Sync（manifest／分桶／revision／防少覆多）；自動同步可在下方關閉
關閉方式
本頁是獨立新增模組：不開本頁或從入口移除卡片即關閉；其他模組不依賴本頁。還原：匯出備份 JSON 後可清除本頁資料庫
最小缺件（要做到真實資料驗收，還需要）
  1. ERP 訂單匯出檔（含 訂單編號、序、自編單號、客戶、款、色、PO、交期、數量），一份近 1–3 個月即可；另一個對話窗擷取完成後直接丟進「匯入 ERP 檔」。
  2. 同期間的 ERP 出貨明細（出貨單號、序、自編單號／訂單編號、數量、出貨日）。
  3. PROD 這台瀏覽器已拉取同期間的車縫／排產／出貨排程（入口頁「智慧拉取全部」）。
